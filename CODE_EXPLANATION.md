# Code Explanation: Multi-Agent Paper Analysis (Flask Edition)

This document provides a comprehensive technical breakdown of the multi-agent paper analysis codebase. It covers the Flask architecture, agent prompt design, API endpoints, frontend styling and reactivity, and installation instructions.

---

## 🏗 System Architecture

The application has been upgraded from a basic Streamlit script to a high-performance **Flask web application** coupled with a reactive modern frontend. The project structure is organized as follows:

```
multi_agent_paper_analysis/
├── app.py                  # Main Flask web server & REST API endpoints
├── agents.py               # AI Agent definitions, prompt logic & Google Gemini SDK wrapper
├── sample_data.py          # Curated research paper excerpts (Attention Is All You Need)
├── streamlit_app.py        # Preserved legacy Streamlit implementation
├── requirements.txt        # Python dependency declarations
├── .env.example            # Template for environment variables
├── templates/
│   └── index.html          # Semantic HTML5 template with Jinja2 bindings
└── static/
    ├── css/
    │   └── style.css       # Custom glassmorphic aurora dark-mode design system
    └── js/
        └── app.js          # Client-side reactivity, parallel dispatch, TTS & Markdown rendering
```

## 🧠 Multi-Agent Orchestration & Prompt Engineering (`agents.py`)

The multi-agent intelligence pipeline divides academic evaluation into four distinct personas. Each persona has a dedicated prompt template that strictly isolates its domain to prevent halo effects and cognitive bias:

### 1. `Summarizer Agent` (📝 Coral Theme)
*   **Persona:** Lead Academic Summarizer & Senior Research Analyst.
*   **Focus Areas:** Core problem statement, primary architectural innovation, quantifiable outcomes (e.g. BLEU scores, accuracy), and scientific impact.
*   **Prompt Strategy:** Instructs the LLM to extract the distilled thesis without delving into hyperparameter minutiae.

### 2. `Methodologist Agent` (🔬 Cyan Theme)
*   **Persona:** Strict Data Scientist, Quantitative Machine Learning Architect.
*   **Focus Areas:** Mathematical formulations, loss functions, neural layer topologies, benchmark datasets, training regimes (GPUs, batch sizes, learning rates), and evaluation metrics.
*   **Prompt Strategy:** Forces mathematical precision and formal representations over high-level generalizations.

### 3. `Critic Agent` (⚖️ Amber Theme)
*   **Persona:** Elite Peer Reviewer for top conferences (NeurIPS/ICLR/Nature).
*   **Focus Areas:** Methodological weaknesses, unverified assumptions, benchmark snooping/leakage, edge case failures, and reproducibility barriers.
*   **Prompt Strategy:** Adversarial prompting designed to challenge claims constructively rather than summarize.

### 4. `Synthesizer Agent` (🧠 Violet Theme)
*   **Persona:** Lead Editor-in-Chief & Chief AI Technology Strategist.
*   **Focus Areas:** Unification of the three primary outputs into an Executive Intelligence Dossier, balanced feasibility scoring, peer-review verdict (Accept/Revise/Reject), and actionable next steps.
*   **Input Context:** Receives the outputs generated by the Summarizer, Methodologist, and Critic agents.

## 🌐 Server Endpoints (`app.py`)

The Flask application exposes modular endpoints:

1.  **`GET /`**: Renders `index.html` with configuration parameters, available models, and agent definitions.
2.  **`GET /api/config`**: Provides runtime status, including whether an environment variable key is active and default model info.
3.  **`POST /api/validate-key`**: Accepts an API key and performs a live query to Google Gemini API to list available models, returning supported options dynamically.
4.  **`POST /api/extract-pdf`**: Ingests an uploaded PDF multipart stream, extracts plain text using `PyPDF2`, validates page counts, sanitizes text, and caps at 100k characters for API performance.
5.  **`GET /api/sample-paper`**: Returns the built-in *Attention Is All You Need* dataset for immediate one-click testing.
6.  **`POST /api/analyze-agent`**: Executes a single agent request given `agent_id`, `context`, `api_key`, and `model_name`. This atomic structure enables the client to launch agents concurrently.
7.  **`POST /api/export-dossier`**: Compiles all agent outputs into a unified, downloadable Markdown dossier file (`.md`).

## 🎨 Frontend Architecture & Stylist UI (`style.css` & `app.js`)

### 1. Glassmorphism & Aurora Design System
*   **Deep Space Canvas:** `#07090e` base with ambient floating CSS aurora blobs (purple, cyan, coral, amber) creating depth.
*   **Translucent Card Surfaces:** `backdrop-filter: blur(20px)` with subtle borders (`rgba(255, 255, 255, 0.08)`).
*   **Vibrant Agent Palettes:** Each agent possesses its own signature neon accent glow, avatar, and active state animations.

### 2. High-Performance Client Reactivity (`app.js`)
*   **Concurrent Execution (`Promise.all`):** When "Deploy Agent Team" is pressed, the browser fires asynchronous calls to `Summarizer`, `Methodologist`, and `Critic` simultaneously. When all three resolve, it feeds their collective output to `Synthesizer`.
*   **Interactive Flow Diagram:** Dynamic SVG/DOM nodes that pulse and transition from "Standby" to "Active" to "Done".
*   **Markdown Parsing:** Uses `marked.js` and `DOMPurify` to render formatted markdown, tables, blockquotes, and code snippets securely.
*   **Audio Briefing:** Utilizes the Web Speech API (`SpeechSynthesis`) to read the executive briefing aloud with Play/Stop toggle controls.
*   **Grid vs. Focus Tabs:** Users can switch between a panoramic 2x2 grid and a tabbed deep dive view with one click.
